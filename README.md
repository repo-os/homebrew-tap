# Repo-os Tap

## How do I install these formulae?

`brew install repo-os/tap/<formula>`

Or `brew tap repo-os/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "repo-os/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
